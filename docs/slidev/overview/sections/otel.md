# OpenTelemetry en bref

<v-clicks>

- **Framework d'observabilité open source** — projet CNCF (2ème plus actif après Kubernetes)
- **Standard unifié** pour la collecte de traces, métriques et logs
- **Vendor-neutral** — compatible avec Jaeger, Prometheus, Grafana, Datadog, etc.
- **Multi-langage** — .NET, Java, Python, Go, JavaScript, et plus
- **OTLP** — un protocole unique pour tous les signaux

</v-clicks>
