# 🔭 Maîtrisez l'Observabilité Applicative

**Un parcours pratique pour instrumenter vos applications .NET et Java avec OpenTelemetry**

---

## Qu'est-ce que ce DoJo ?

Ce DoJo est un parcours d'apprentissage **hands-on** conçu pour vous guider pas à pas dans l'instrumentation de vos applications avec [OpenTelemetry](https://opentelemetry.io/). Vous apprendrez à collecter, exporter et visualiser les **trois signaux d'observabilité** — traces, métriques et logs — à travers une application concrète : **ShopTrack**.

:::tip Approche pratique
Chaque étape du DoJo combine théorie et exercices concrets. Vous travaillerez sur une vraie application avec une infrastructure d'observabilité complète (Jaeger, Prometheus, Grafana, Loki).
:::

---

## Les 3 Signaux

L'observabilité applicative repose sur trois signaux complémentaires :

<div style={{display: 'flex', gap: '1.5rem', flexWrap: 'wrap', justifyContent: 'center', margin: '2rem 0'}}>

<SignalBadge signal="traces" title="Traces">
  Suivez le parcours d'une requête à travers vos services distribués. Les traces révèlent **où** le temps est passé et **comment** les services interagissent.
</SignalBadge>

<SignalBadge signal="metrics" title="Métriques">
  Mesurez les performances de votre application avec des compteurs, histogrammes et jauges. Les métriques répondent à la question **« comment se porte mon système ? »**.
</SignalBadge>

<SignalBadge signal="logs" title="Logs">
  Capturez les événements structurés et corrélés avec les traces. Les logs fournissent le **contexte détaillé** pour diagnostiquer les problèmes.
</SignalBadge>

</div>
