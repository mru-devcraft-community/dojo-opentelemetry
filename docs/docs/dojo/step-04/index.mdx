<SignalBadge signal="traces" title="Traces — Enrichissement des Spans">
Dans cette étape, vous allez apprendre à enrichir vos spans avec des **attributs métier**, des **events** ponctuels et des **statuts d'erreur**. Ces informations transforment vos traces en véritables outils de diagnostic.
</SignalBadge>

## Pourquoi enrichir les spans ?

Une span vide vous indique simplement qu'une opération a eu lieu. En ajoutant des attributs, des events et des statuts, vous obtenez :

| Enrichissement | Utilité | Exemple |
|---|---|---|
| **Attributs** | Données métier associées à l'opération | `order.customer_name`, `order.items_count` |
| **Events** | Points dans le temps au sein d'une span | `OrderValidated`, `StockChecked` |
| **Status** | Résultat de l'opération (OK, Error) | Erreur de validation de stock |

:::info Conventions OpenTelemetry
Les attributs suivent les [Semantic Conventions](https://opentelemetry.io/docs/specs/semconv/). Utilisez le format `namespace.attribut` en snake_case pour vos attributs métier.
:::

## 1. Ajouter des attributs métier

Les attributs sont des paires clé-valeur attachées à une span. Ils permettent de filtrer et rechercher dans Jaeger.

<Tabs groupId="stack" defaultValue="dotnet" values={[{label: '.NET 10 / Aspire', value: 'dotnet'}, {label: 'Java 21 / Spring Boot', value: 'java'}]}>
<TabItem value="dotnet">

En .NET, les spans sont représentées par des `Activity`. On utilise `SetTag()` pour ajouter des attributs :

```csharp
// Dans votre endpoint de création de commande
app.MapPost("/api/orders", async (CreateOrderRequest request) =>
{
    using var activity = ActivitySources.Main.StartActivity("CreateOrder");

    // Attributs métier sur la span
    activity?.SetTag("order.customer_name", request.CustomerName);
    activity?.SetTag("order.items_count", request.Items.Count);
    activity?.SetTag("order.total_amount", request.Items.Sum(i => i.Price * i.Quantity));

    // ... logique métier
});
```

:::tip Types supportés
`SetTag()` accepte `string`, `int`, `long`, `double`, `bool` et leurs tableaux. Évitez les objets complexes.
:::

</TabItem>
<TabItem value="java">

En Java, on utilise `Span.current()` ou un span injecté, puis `setAttribute()` :

```java
@PostMapping("/api/orders")
public ResponseEntity<OrderResponse> createOrder(@RequestBody CreateOrderRequest request) {
    Span span = Span.current();

    // Attributs métier sur la span
    span.setAttribute("order.customer_name", request.getCustomerName());
    span.setAttribute("order.items_count", request.getItems().size());
    span.setAttribute("order.total_amount", calculateTotal(request.getItems()));

    // ... logique métier
}
```

:::tip Types supportés
`setAttribute()` accepte `String`, `long`, `double`, `boolean` et leurs tableaux via `AttributeKey<T>`. Évitez les objets complexes.
:::

</TabItem>
</Tabs>

## 2. Ajouter des events

Un event est un point dans le temps au sein d'une span. Il représente un moment précis — comme une validation réussie ou une étape franchie.

<Tabs groupId="stack" defaultValue="dotnet" values={[{label: '.NET 10 / Aspire', value: 'dotnet'}, {label: 'Java 21 / Spring Boot', value: 'java'}]}>
<TabItem value="dotnet">

```csharp
// Event simple
activity?.AddEvent(new ActivityEvent("OrderValidated"));

// Event avec des attributs
activity?.AddEvent(new ActivityEvent("OrderPersisted", tags: new ActivityTagsCollection
{
    { "order.id", order.Id.ToString() },
    { "order.status", "Created" }
}));
```

:::warning Attention
Les events ne remplacent pas les spans enfants. Utilisez un event pour un instant ponctuel, une span enfant pour une opération avec une durée.
:::

</TabItem>
<TabItem value="java">

```java
// Event simple
span.addEvent("OrderValidated");

// Event avec des attributs
span.addEvent("OrderPersisted", Attributes.of(
    AttributeKey.stringKey("order.id"), order.getId().toString(),
    AttributeKey.stringKey("order.status"), "Created"
));
```

:::warning Attention
Les events ne remplacent pas les spans enfants. Utilisez un event pour un instant ponctuel, une span enfant pour une opération avec une durée.
:::

</TabItem>
</Tabs>

## 3. Gérer les statuts d'erreur

Quand une opération échoue, marquez la span avec un statut `Error`. Jaeger colorera ces spans en rouge, facilitant le diagnostic.

<Tabs groupId="stack" defaultValue="dotnet" values={[{label: '.NET 10 / Aspire', value: 'dotnet'}, {label: 'Java 21 / Spring Boot', value: 'java'}]}>
<TabItem value="dotnet">

```csharp
try
{
    await ValidateStock(order);
    activity?.AddEvent(new ActivityEvent("StockValidated"));
}
catch (InsufficientStockException ex)
{
    // Marquer la span en erreur
    activity?.SetStatus(ActivityStatusCode.Error, ex.Message);

    // Ajouter un event d'échec avec détails
    activity?.AddEvent(new ActivityEvent("StockValidationFailed", tags: new ActivityTagsCollection
    {
        { "error.type", ex.GetType().Name },
        { "error.message", ex.Message },
        { "order.item_id", ex.ItemId.ToString() }
    }));

    throw;
}
```

:::danger Ne pas oublier
Appelez toujours `SetStatus(ActivityStatusCode.Error, ...)` **avant** de relancer l'exception. Sinon la span peut se fermer sans le statut d'erreur.
:::

</TabItem>
<TabItem value="java">

```java
try {
    validateStock(order);
    span.addEvent("StockValidated");
} catch (InsufficientStockException ex) {
    // Marquer la span en erreur
    span.setStatus(StatusCode.ERROR, ex.getMessage());

    // Ajouter un event d'échec avec détails
    span.addEvent("StockValidationFailed", Attributes.of(
        AttributeKey.stringKey("error.type"), ex.getClass().getSimpleName(),
        AttributeKey.stringKey("error.message"), ex.getMessage(),
        AttributeKey.stringKey("order.item_id"), ex.getItemId().toString()
    ));

    throw ex;
}
```

:::danger Ne pas oublier
Appelez toujours `setStatus(StatusCode.ERROR, ...)` **avant** de relancer l'exception. Sinon la span peut se fermer sans le statut d'erreur.
:::

</TabItem>
</Tabs>

## 💡 Indices

<details>
<summary>Où placer les SetTag / setAttribute ?</summary>

Ajoutez les attributs **le plus tôt possible** dans la span, idéalement dès que vous avez les données. Les events peuvent être ajoutés à tout moment pendant la durée de vie de la span.

</details>

<details>
<summary>Comment voir les events dans Jaeger ?</summary>

Cliquez sur une span dans le timeline de Jaeger. Dans le panneau de détail, vous trouverez un onglet **Logs** (c'est le nom historique pour les events dans Jaeger). Chaque event y apparaît avec son timestamp et ses attributs.

</details>

<details>
<summary>Les attributs n'apparaissent pas ?</summary>

Vérifiez que votre `Activity` n'est pas `null`. En .NET, `StartActivity()` retourne `null` si aucun listener n'est actif. Utilisez toujours l'opérateur `?.` (null-conditional).

</details>
