# Démarrage Rapide

Bienvenue ! Cette section vous guide pour préparer votre environnement et lancer le DoJo OpenTelemetry.

## Vue d'ensemble

Avant de commencer les exercices, vous aurez besoin de :

1. **Un moteur de conteneurs** — Docker ou Podman pour exécuter l'infrastructure d'observabilité
2. **Un SDK de développement** — .NET 10 ou Java 21 selon la stack choisie
3. **Un IDE** — VS Code, IntelliJ IDEA, ou Rider
4. **Git** — pour cloner le dépôt

:::tip Deux parcours disponibles
Le DoJo propose un parcours **.NET** et un parcours **Java**. Choisissez celui qui correspond à votre stack, ou suivez les deux pour comparer les approches !
:::
